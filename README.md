# SmartPayBot

SmartPayBot monitora oportunidades do 99Freelas, cruza projetos com palavras-chave dos usuarios e envia alertas pelo fluxo atual:

`coletor local -> VPS -> SQLite -> matcher -> notifier -> Telegram`
